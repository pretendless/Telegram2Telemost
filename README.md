# Telegram → Telemost stickers

Перенос стикерпаков из Telegram в стикеры Яндекс Телемоста.

Источник списка — канал [t.me/tg2tm](https://t.me/tg2tm). Каждое сообщение канала — один будущий пак в Телемосте: первая строка это название, дальше ссылки `t.me/addstickers/...` в нужном порядке. Никита уже уложил каждое сообщение в лимит Телемоста (не больше 150 стикеров на пак).

На компьютере Никиты репозиторий лежит в `D:\Telemost2Telegram`.

## Как устроено

| Путь | Что там |
| --- | --- |
| `packs/NN-slug/` | Один пак. `pack.json` и файлы `001.png`, `002.png`, … в том же каталоге. |
| `config/settings.json` | Канал-источник и лимиты бота Телемоста. |
| `docs/` | Как устроен бот Телемоста и откуда брать файлы из Telegram. |
| `logs/transfer-log.md` | Ход переноса: пак, стикер, статус, ошибки. |
| `scripts/validate_packs.py` | Проверка, что папки и `pack.json` сходятся. |

Имена каталогов только ASCII, чтобы их нормально открывал Windows.

## Как забрать обновления

```bat
cd /d D:\Telemost2Telegram
git fetch origin
git checkout cursor/repo-layout-9d8d
git pull origin cursor/repo-layout-9d8d
```

Картинки появятся рядом с `pack.json` по мере скачивания. `stickerCount` в `pack.json` заполняется, когда известно число стикеров по всем ссылкам сообщения. Пока известен только набор `bandit_vk` (48 стикеров) — это не весь пак «Бандит и Лисы».

## Поля pack.json

- `title` — название пака, как в сообщении канала.
- `sourceMessage` — ссылка на это сообщение (`https://t.me/tg2tm/<id>`).
- `stickerLinks` — ссылки на наборы Telegram, по порядку.
- `stickerCount` — сколько стикеров войдёт в пак Телемоста, или `null`, если ещё не посчитано.
- `images` — имена файлов в этом каталоге, в том же порядке.
- `telemost.status` — `pending`, `uploading`, `done` или `error`.

## Лимиты Телемоста

Бот «Стикеры» в мессенджере Телемоста принимает JPEG или PNG, от 512×512, высота не больше ширины, до 512 КБ, по одной картинке. В паке до 150 стикеров, у пользователя до 100 паков. Команды: `/newpack`, `/addsticker`, `/done`. Подробности в `docs/telemost-sticker-bot.md`.

Стикеры Telegram чаще всего приходят как `.webp`, `.tgs` или `.webm`. В бота Телемоста уходит PNG (или JPEG), поэтому анимированные и видеостикеры нужно отдельно решать: в лимит «картинка» они не входят.

## Проверка списка

```bash
python scripts/validate_packs.py
```
