# Формат заявки на пак и бот

## Канал-образец

Канал с образцами: [t.me/tg2tm_samples](https://t.me/tg2tm_samples). До 12 октября 2026 он назывался `t.me/tg2tm`, но публичное имя сменили, чтобы освободить `tg2tm`. Канал и сообщения остались на месте. Старые ссылки вида `t.me/tg2tm/<id>` теперь живут как `t.me/tg2tm_samples/<id>`.

## Формат: одно сообщение — один пак

```
<название пака>

https://t.me/addstickers/<набор 1>
https://t.me/addstickers/<набор 2>
…
```

- Первая строка — название пака в Телемосте.
- Дальше ссылки на наборы Telegram, по одной в строке. Порядок ссылок задаёт порядок стикеров.
- Всего не больше 150 стикеров на сообщение: столько Телемост разрешает в одном паке.

Пример из канала:

```
Минто

https://t.me/addstickers/minty_vk
https://t.me/addstickers/minty2_vk
```

(в канале у «Минто» есть ещё третья ссылка, `minto3_vk`).

## Бот @tg2tm

Не создан. BotFather отказал на шаге выбора имени:

> Sorry, the username must end in `bot`. E.g. Tetris_bot or Tetrisbot.

Telegram не даёт ботам имя без окончания `bot`, так что `@tg2tm` как бот не получится. Создание отменено (`/cancel`). Имя `tg2tm` пока свободно. Описание, «о боте», список команд и ответ `/start` не настраивались.

Варианты, если всё же нужен бот: `@tg2tm_bot` или `@tg2tmbot`. Выбор за владельцем.

## Токен

Для скачивания стикеров через Bot API используется отдельный служебный бот. Его токен лежит только в `config/bot.token`; файл в `.gitignore` и в git не попадает. Скрипт `scripts/fetch_and_convert.py` берёт токен из переменной `TELEGRAM_BOT_TOKEN`:

```bash
TELEGRAM_BOT_TOKEN=$(cat config/bot.token) python scripts/fetch_and_convert.py
```
