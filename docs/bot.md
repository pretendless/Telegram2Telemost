# Бот @tg2tmbot

Отображаемое имя: **Telegram2Telemost**. Имя пользователя: [@tg2tmbot](https://t.me/tg2tmbot).

Канал [t.me/tg2tm](https://t.me/tg2tm):

- название: «Стикеры TG → Телемост»;
- описание: «Готовые наборы стикеров, перенесённые в Телемост. Каждый пост — один набор и ссылка на него.»

Ранние посты канала — история и к формату запроса не относятся. Канал публикует только уже перенесённые наборы: один пост на пак, название и ссылка Телемоста. Пример запроса бот показывает сам, в `/start`, `/format` и `/example`.

## Профиль бота

- Имя: `Telegram2Telemost`
- О боте: «Переносит стикеры из Telegram в Телемост.»
- Описание:

```
Telegram2Telemost переносит стикеры из Telegram в Телемост.

Одно сообщение — один пак: первая строка — название, дальше ссылки t.me/addstickers/… по порядку, всего до 150 стикеров.

Пример:
Минто

https://t.me/addstickers/minty_vk
https://t.me/addstickers/minty2_vk

Бот проверяет набор и сообщает о ходе загрузки. Готовые наборы: https://t.me/tg2tm
```

Команды: `/start` — «Как пользоваться», `/format` — «Формат запроса», `/example` — «Пример набора», `/status` — «Ход переноса», `/stop` — «Отписаться».

## Формат запроса

Одно сообщение — один пак:

```
<название пака>

https://t.me/addstickers/<набор 1>
https://t.me/addstickers/<набор 2>
```

Первая строка — название. Дальше ссылки по одной в строке, не больше 150 стикеров.

Пример:

```
Минто

https://t.me/addstickers/minty_vk
https://t.me/addstickers/minty2_vk
```

`/start` называет бота Telegram2Telemost и даёт ссылку на канал готовых наборов: https://t.me/tg2tm

## Что отвечает бот

| Команда или сообщение | Ответ |
| --- | --- |
| `/start` | Как пользоваться, пример, ссылка на канал, подписка на ход переноса |
| `/format` | Правила и пример |
| `/example` | Только пример |
| `/status` | Каждый пак: ждёт / загружается / готов, сколько загружено, ссылка если она уже есть |
| `/stop` | Отписка |
| сообщение в формате пака | Название, число стикеров в каждом наборе и укладывается ли пак в 150 |

В Телемост бот сам ничего не загружает. Это делает Chrome на машине переноса (`scripts/telemost_upload.mjs`, `scripts/telemost_links.mjs`). После записи `pack.json` скрипт `scripts/report_progress.mjs` шлёт `POST /progress` воркеру.

## Уведомления

Тем, кто отправил `/start`:

- начата загрузка;
- 25 %, 50 % и 75 %;
- ошибка, на которой загрузка остановилась;
- «готово» — только когда есть настоящая `telemost.packUrl`, и в том же сообщении ссылка на канал https://t.me/tg2tm. Пока ссылки нет, ни «готово», ни пост в канал не уходят. Если «готово» уже уходило без ссылки, бот досылает ссылку и после этого публикует пост.

Подписчики, отправленные уведомления и статус паков лежат в Workers KV. При первом обращении в пустое KV записывается подписчик с chat id `8502935020`; после `/stop` он сам не возвращается. Состояние уведомлений воркер начинает заново.

## Пост в канале

Когда `telemost.packUrl` известна (у Телемоста она в кнопке, не в тексте «Набор «…» сохранён и доступен по ссылке.»):

```
«<название>»

<ссылка на пак в Телемосте>
```

В посте нет ссылок `t.me/addstickers/…` и нет ссылки на старое сообщение канала. Бот — администратор канала с правом публиковать сообщения.

## Где работает

Круглосуточно — Cloudflare Worker в `worker/`: Telegram шлёт обновления на `POST /telegram`, загрузчик — на `POST /progress`. Архитектура, локальные тесты и выкладка — в `worker/README.md`.

```bash
cd worker && node --test
```

Пока вебхук не включён, отвечает `python scripts/tg2tmbot.py` (long polling). Включать оба сразу нельзя: вебхук ломает `getUpdates`.

Описание, «о боте» и команды: `python scripts/tg2tmbot.py --setup` или `npm run setup-bot` в `worker/`.

## Токены

Токены в git не попадают (`*.token` в `.gitignore`):

- `config/tg2tmbot.token` — бот @tg2tmbot;
- `config/bot.token` — служебный бот, через который `fetch_and_convert.py` скачивает стикеры.

Секреты воркера задаются через `wrangler secret put`, не через файлы репозитория: `TG2TMBOT_TOKEN` (или `TELEGRAM_BOT_TOKEN`), `WEBHOOK_SECRET`, `UPLOADER_SECRET`.

## История имени

12 октября 2026 канал ненадолго переименовали в `t.me/tg2tm_samples`, чтобы отдать имя `tg2tm` боту. BotFather отказал: «Sorry, the username must end in `bot`». Канал вернули на `t.me/tg2tm`, бот получил имя пользователя `tg2tmbot`, отображаемое имя — Telegram2Telemost.
