# Откуда брать файлы стикеров

## Источник списка

Канал [t.me/tg2tm](https://t.me/tg2tm) («Бот Стикеры в ТМ»). Публичный просмотр: [t.me/s/tg2tm](https://t.me/s/tg2tm).

В канале 8 сообщений со стикерами (посты 2, 4, 5, 6, 7, 8, 9, 10; поста 3 нет). Каждое сообщение — один пак Телемоста. Разбор записан в `packs/*/pack.json`.

## Как скачиваем

Через Bot API, служебным ботом (токен в `config/bot.token`, см. `docs/bot.md`):

1. `getStickerSet` по имени набора из ссылки — список стикеров в порядке набора, эмодзи и тип каждого.
2. `getFile` и загрузка оригинала: `.webp` (статичный), `.tgs` (Lottie) или `.webm` (видео).
3. `scripts/fetch_and_convert.py` делает из каждого PNG 512×512 на прозрачном фоне до 512 КБ.

Так получаем исходные файлы в правильном порядке, без чужих ботов и архивов. Ничего не нужно отправлять в чаты.
