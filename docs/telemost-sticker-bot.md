# Бот стикеров Телемоста

Проверено 12 октября 2026 в уже открытом чате мессенджера на `telemost.yandex.ru`. После входа Яндекс ID страница Телемоста открылась, спиннер «Подключение…» больше не висел. Чат с ботом называется **Стикеры**.

До входа, с этой машины (регион у Яндекса определялся как США), `https://telemost.yandex.ru` оставался на «Подключение…» / «Попытка подключения повторится через N секунд». Вход это снял.

## Команды, которые бот сам прислал на `/start`

| Команда | Что делает |
| --- | --- |
| `/start` | Показать команды |
| `/newpack` | Создать набор |
| `/addsticker` | Добавить стикер в существующий набор |
| `/seticon` | Задать иконку набора (в справке Яндекса этой команды нет, в живом боте есть) |
| `/delsticker` | Удалить стикер |
| `/deletepack` | Удалить набор |
| `/done` | Завершить действие |

Ответ на `/start` пришёл в ту же минуту. Медленной выглядит загрузка картинок, не список команд. Скорость загрузки ещё не замерена: в бота пока ничего не отправлялось.

## Лимиты

По [справке Яндекс 360](https://yandex.ru/support/yandex-360/customers/messenger/ru/stickers) и [заметке от 22.07.2026](https://360.yandex.com/blog/guides/stikeri-na-vse-sluchai-kak-sozdat-svoi-nabor-v-messendzhere-i-telemoste/):

- формат только JPEG или PNG (не WebP, не TGS, не WebM);
- от 512×512 px;
- высота не больше ширины;
- файл до 512 КБ;
- картинки только по одной;
- на каждый стикер бот просит эмодзи;
- до 150 стикеров в наборе;
- до 100 наборов у одного пользователя;
- фон бот сам не вырезает;
- если файл не подходит, бот пишет об этом и ждёт другую картинку;
- после `/done` у набора появляется ссылка;
- чтобы пак был в панели стикеров, его нужно добавить: нажать стикер → «Добавить стикеры».

Порядок стикеров потом можно менять тем же ботом. Для переноса держим порядок ссылок из сообщения канала.

Эти же числа лежат в `config/settings.json`.
